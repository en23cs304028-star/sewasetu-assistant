What Failed and What We Changed

Real defects and edge cases discovered during actual evaluation runs, with before/after fixes.

Area / Scenario Before (Failure Encountered) After (Fix Implemented)
PostgreSQL Key Collision
applications_pkey sequence
Failure: Bulk importing seed.sql using SQL COPY did not advance applications_id_seq, causing UniqueViolation: duplicate key value violates unique constraint 'applications_pkey' on the next submit_application.
Fix: Synchronized all sequences via SELECT setval('applications_id_seq', (SELECT max(id) FROM applications)) and harmonized sequence resets in DB setup and test teardown.
Simulator Premature Exit
Persona Simulator Turns
Failure: Simulator LLM said "done" on turn 1 after answering general scheme questions, cutting off interaction before the assistant could call prepare_application or submit_application.
Fix: Refined simulator system prompt so "done" is strictly reserved for full completion/rejection, and instructed simulator to answer requests for missing details and grant explicit declaration confirmation.
SMS Gateway URL Discovery
Headless OTP Delivery
Failure: services.send_sms read http://smsgw:8025 strictly from app.ini without checking environment overrides, causing OTP dispatch to fail when running headlessly on host.
Fix: Added os.environ.get('SMS_GATEWAY_URL') check in services.send_sms and app/app.py, enabling transparent OTP delivery to simulated gateway inbox.
Boundary Age 60 Leap-Year Trap
Persona 07 (Renu Ali)
Failure: Using floating-point day math (today - dob).days / 365.25 failed on exact 60th birthday for applicants born on leap years.
Fix: Implemented exact calendar tuple comparison (today.year - dob.year) - ((today.month, today.day) < (dob.month, dob.day)) in services.age_on.
Unreasoned Officer Rejections
Persona 11 (Natural Justice)
Failure: Officers could reject applications with empty reasons, violating statutory accountability rules.
Fix: Enforced non-empty recorded justification at domain service level (services.decide_application), preventing arbitrary statutory denials.
MCP Tool Schema Attributes
Official MCP SDK Client
Failure: Official Python mcp SDK 2.3.0 pydantic models expose input_schema rather than camelCase inputSchema, causing attribute error during tool translation.
Fix: Handled both input_schema and inputSchema with getattr(t, "input_schema", getattr(t, "inputSchema", {})).
